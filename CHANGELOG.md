# Changelog

Releases are published automatically on every merge to `main`; see the
[releases page](https://github.com/jihanurrahman33/Claude-Usage-Widget/releases)
for the notes of each version. This file records the first version only.

## 0.1.0 (2026-11-13)

First version.

- Rings for 5-hour and 7-day limits, with reset countdowns.
- Gateway spend and API-key cost views.
- Status line bridge with one-switch install and restore.
- Tray icon, launch at login, alerts at 80% and 95%, opacity slider.
- Always on Top switch; on Linux the widget runs on X11 so it works.
- Glass starts at its clearest setting, with a text halo for legibility.
- Light and dark themes.
- One-line Linux installer that downloads the latest release and verifies its
  checksum; running it again updates the app.
- Linux tested; macOS and Windows build in CI but have not been run.
